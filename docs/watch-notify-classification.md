# 特許ウォッチ・通知・分類辞書・審査基準（v0.2）

## 特許ウォッチ

- 案件の「ウォッチ」タブで、収集元（EPO OPS の CQL、GDELT の検索語、RSS、USPTO、JPO）と間隔（最短 6 時間）を登録する。
- スケジューラ（1 スレッド、10 分ごとに起床。タイマーは RAM のみ）が期限の来たウォッチを実行し、**新規に追加された文書だけ**を
  案件の名称・最新請求項・解決手段の語（2-gram の OR 検索、BM25＋ベクトル）で順位付けしてヒットとして保存する。
- ヒットは「関連→Y」「X」で先行文献に登録、「対象外」で除外。新しいヒットは通知される。
- API: `GET/POST /api/v1/watches`, `POST /api/v1/watches/{id}/run`, `GET /api/v1/watch-hits?patent_id=`, `POST /api/v1/watch-hits/{id} {status, category}`。MCP: `watch_hits`。

## 通知

- 設定 > 通知: Webhook（`json` = 汎用 JSON / ControlDeck、`discord`、`slack`）とメール（SMTP、パスワードは外部キー）。
- 期限通知: 毎日 1 回、各案件の期限（目安）が設定日数（既定 60/30/7 日前）以内に入ったら、しきい値ごとに 1 回だけ送る（`notify_log`）。
- 送信先は管理者だけが設定できるため、LAN 内アドレス（ControlDeck 等）も許可している。

## 分類辞書（IPC / FI / Fターム / CPC / ICS）

- 種別 `classification` のコレクションを作り、取り込み形式「分類コード表」で `コード<TAB>説明` の行を貼り付ける（1 行 1 コード）。
- 入手先の例: WIPO の IPC（日本語版は特許庁の IPC 公開資料）、J-PlatPat の「特許・実用新案分類照会（PMGS）」で表示した FI/Fターム一覧、EPO の CPC スキーム。
  いずれも各サイトの利用条件に従い、手作業で入手したものを取り込む（自動取得はしない）。
- `GET /api/v1/classify?q=` と MCP `classify` でコードを検索。AI 支援の「検索式の設計」「新規性」「新規発明の創出」は分類候補を自動でプロンプトに入れる。

## 審査基準・法令

- 種別 `law` のコレクションに、特許・実用新案審査基準、特許法などのテキストを取り込む（PDF は別PCでテキスト化して投入）。
- AI 支援の新規性・進歩性・請求項ドラフト・明細書・出願前チェック・拒絶理由対応・侵害・FTO・方針の各タスクは、`law` から関連箇所を最大 4 件取り出し `[基準n]` として引用させる。
